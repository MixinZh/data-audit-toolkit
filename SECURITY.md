# Security policy

## Supported versions

Security fixes are considered for version `0.1.x`.

## Reporting a vulnerability

Do not attach sensitive datasets, credentials, or private artifacts to public issues. Use GitHub private vulnerability reporting for this repository when it is available. If private reporting is not available, wait for a private reporting route rather than disclosing sensitive details publicly.

Reports should identify the affected version, describe the security impact, and include a minimal synthetic reproduction when possible.
